# 看图清单

`shoot.py` 会在电脑（1440×900）和手机（390×844）两种屏幕上逐个画面截图：开场、每章开场、每个场景演出中途、章末、总览。机器能查出来的问题写进 `qa/shots.json`，每条带「怎么改」。机器查不出来的，要打开 `qa/sheet-*.png` 拼版图逐张看。

```bash
python3 scripts/shoot.py <项目>                 # 两种屏幕都拍，约 3–5 分钟
python3 scripts/shoot.py <项目> --only mobile   # 只拍手机
python3 scripts/shoot.py <项目> --ch 3          # 只拍第 3 章（也可写 2,5 或章节 id）
```

第一次拍要联网下载影像和高程瓦片，之后读本地缓存（`~/.cache/history-map3d/web`），重拍一章只要几秒。

## 机器报的问题

| 代码 | 意思 | 怎么改 |
|---|---|---|
| `MAP_BLANK` | 地图没画出来 | 确认能联网；再试 `--soft-gl` |
| `JS_ERROR` / `PAGE_DEAD` | 页面脚本报错 / 没跑起来 | 先跑 build.py 看检查报告；还不行把报错原文写进 `qa/notes.md` |
| `SCENE_NOT_FIRED` | 场景没触发 | 跑 check.py，看有没有 `NOT_ON_TRACK` |
| `FOCUS_HIDDEN` | 演出中心被卡片挡住 | 调 `scene.b` 转个方向，或换一个 `scene.at` |
| `SCENE_OFFSCREEN` | 特效、兵力跑出画面 | `scene.z` 调小 0.5，或把偏移缩到 ±25 公里以内 |
| `OVERLAP` / `OFF_SCREEN` | 卡片互相重叠 / 超出屏幕 | 缩短卡片里的文字 |
| `TEXT_CLIPPED` / `WRAP` | 字被裁掉 / 标题折行 | 场景标题 ≤ 10 字，章标题 ≤ 5 字，巡游小标题 ≤ 12 字 |
| `SUB_LINES` | 一句字幕折成三行以上 | 拆成两句，手机上一句最好 ≤ 18 字 |
| `LABEL_OVERLAP` | 两个地名叠在一起（提示） | 其中一个的 `z` 调大 0.5–1，或挪开一点 |
| `TILES_SLOW` / `NET_FAIL` | 瓦片没加载完 / 网络失败 | 重拍，不用改故事 |

## 人要看的

逐张看拼版图，每张问自己：

1. **主体在不在画面里**：场景演出时，城、山、河、人物符号露出来了吗？有没有被场景卡、字幕、诗卡盖住？
2. **路线走得合不合理**：有没有横穿山脊、穿过海面、绕到对岸？水路是不是贴着河走？不合理就在 `routes.json` 加拐点。
3. **地名有没有叠在一起**，有没有重要的地方没标名字。
4. **手机上**：字有没有被截断，按钮有没有被卡片压住，诗卡、字幕是不是都读得到。
5. **颜色**：相邻两章主色分得开吗？路线和底图分得清吗？
6. **文字**：标题、字幕有没有错字，有没有浮夸词，有没有先否定再转折的对举句（check.py 的 NOT_BUT 规则）。

改完重跑 `build.py`，再用 `--ch` 只拍改过的章，直到 0 错误 0 警告、拼版图看过一遍。
